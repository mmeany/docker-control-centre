# Docker Control Centre: project guide

Explorer-style desktop app built with Tauri 2, React and Rust. Started from
the Tauri desktop template (the look, shell and plumbing of AWS Explorer).
Code is generated by Claude to specs from the owner.

## Architecture decisions (agreed; don't change without asking)

- **Shell:** Tauri 2. Uses the OS webview (WebView2 on Windows), so browser-engine
  security patches come from OS updates, not app rebuilds.
- **Frontend:** React + Vite + TypeScript. UI only: no secrets, no network calls,
  no file access. `src/api/` is the only place that calls Tauri, so the UI also
  runs in a plain browser (that's how `tools/ui-check` works).
- **Backend:** Rust does ALL file, network and OS work. Commands are thin;
  logic lives in modules with unit tests beside it.
- **Settings:** JSON at `<app config dir>/settings.json` (Windows:
  `%APPDATA%\com.mmeany.dockercontrolcentre\`). Non-secret only. Small
  per-section values go in `values` (keys prefixed with the section id); bigger
  data gets its own file. The bundle identifier names that folder, so don't
  change it after release.
- **Theme:** System / Light / Dark, saved in settings. System follows the OS
  live (dark if the OS can't say); the native title bar follows via `setTheme`
  (needs `core:window:allow-set-theme`). **All CSS colours are tokens** in
  `styles.css` with light AND dark values: never hard-code a colour in a rule.
- **Look and feel:** classic Explorer: tree on the LEFT, details list on the
  right, three toolbar rows (app row; command bar; back/forward/up + address
  bar + copy + refresh), status bar, Explorer keyboard shortcuts, 12px Segoe UI.

## Dependency policy

Minimise shipped dependencies; every addition needs a reason.
- Shipped JS: `react`, `react-dom`, `@tauri-apps/api`. No UI kit, no icon
  library, no state library. Plain CSS.
- Rust: `tauri`, `tauri-plugin-dialog`, `serde`, `serde_json`
  (`preserve_order`), `tokio` (sync, fs, io-util, rt, time). Disable unneeded
  crate features. Run `cargo audit` before releases.
- Native dialogs are opened from Rust commands (`pick_folder`,
  `pick_open_file`, `pick_save_file`), so there is no JS dialog plugin and no
  dialog permissions in capabilities.
- Build tools (vite, typescript, tauri-cli) and Playwright (UI checks) aren't
  shipped.
- If the app needs TLS (HTTP clients, AWS SDK): rustls + ring, default features
  off, so Windows builds need only the MSVC Build Tools (no CMake/NASM, no
  OpenSSL).

### Shared components

- `FileList`: virtualised details view (sort, multi-select, keyboard, context
  menu, `dimmed` rows). Fixed ROW_H = 22px, must match `.fl-row` CSS.
- `TreeRow` / `TreeNote`: tree rows with twisty, selection, context menu.
- `CommandButton` / `CommandSeparator`: command-bar buttons.
- `FilterBox`: text filter with remembered history (`appApi.rememberFilter`),
  optional extra controls as children. `#filter-input` takes Ctrl+F if you wire it.
- `PageBar`: First / Previous / Next with a 100 / 500 / 1,000 page-size list.
- `ConfirmDialog` (`shell.ask`), `PromptDialog` (`shell.askName`, with
  validation), `TypedConfirmDialog` (`shell.confirmTyped`, for irreversible
  actions), `ContextMenu` (`shell.openMenu`).
- `ValueView` (text, or a DataTree for JSON), `ValueEditor` (JSON check,
  Format / Minify, optional masking), `DataTree` (expand all / to level, big
  arrays paged), `MaskedValue` (Reveal / Copy for secrets: plaintext only in
  component state), `DiffView` + `util/diff.ts`.
- `ErrorPanel` (in place of content, with Retry), `StatusBar`, `Toolbar`, `Icons`
  (inline SVG).
- CSS building blocks: `.section-pane`, `.filter-bar`, `.detail-view` +
  `.stat-tiles` + `.props-table` + `.props-section`, `.data-table`, `.kv-rows`,
  `.form-grid`, `.dialog` + `.dialog-wide` / `.preview-dialog`, `.segmented`,
  `.badge-info` / `.badge-warn`, `.warn-note` / `.ok-note`, `.progress`,
  `.live-dot`.

## Adding a section

1. `src/sections/<id>/use<Id>Section.tsx`: a hook taking `Shell`, returning
   `SectionUi`. Active when `shell.place.section === "<id>"`; `place.path` is
   whatever the section decides (folder, record id, "" for its root).
2. Register it in `src/sections/index.ts` (name, description, icon, `root`,
   and `crumbs` / `parent` / `uri` if paths have levels).
3. Backend: `src-tauri/src/<id>.rs` (logic + tests) and
   `src-tauri/src/commands/<id>.rs` (thin commands), `pub mod <id>;` in
   `commands/mod.rs`, `mod <id>;` in `lib.rs`, commands in `generate_handler!`.
4. `src/api/<id>.ts` with typed wrappers.
5. Mock the new commands in `tools/ui-check/mock-ipc.js` and add a scenario.
6. Docs: README section list; this file.

The sample section (`sections/files`, `files.rs`) shows every pattern. Remove
it with `node scripts/rename.mjs --name "…" --no-sample` at the start, or by
hand later (lines marked `// sample`).

## Rules

- Commands return `Result<T, AppError>`; the UI switches on `kind`
  (`notFound`, `accessDenied`, `invalid`, `other`). Add kinds in both
  `error.rs` and `api/core.ts`.
- Serde uses camelCase across the boundary. Tagged enums also need
  `rename_all_fields = "camelCase"`.
- State tied to a place (filters, page, search) is stored with the path it
  belongs to, so navigating can't apply it to another place for a render.
- Async effects guard against stale responses (`let stale = false` … cleanup).
- Destructive actions confirm; irreversible ones (deleting something that can't
  come back) use `shell.confirmTyped`.
- Secrets: never cached, logged or put in settings; reveal on demand only.
- Every user-facing string is plain English, sentence case; no exclamation marks.
- Explorer shortcuts: Enter open, Backspace / Alt+↑ up, Alt+← / Alt+→ back /
  forward, F5 refresh, Del delete, F2 rename, Ctrl+Shift+N new, Ctrl+E edit,
  Alt+Enter properties.

## Testing

- `cd src-tauri && cargo test`: unit tests (each module has its own).
- `npm run build`: typecheck + frontend build.
- `npm run ui:check -- [scenario] [--light|--both]`: headless screenshots of the
  UI with the IPC mocked (`tools/ui-check/out/`). Needs Playwright once:
  `npm i -D playwright && npx playwright install chromium`. Look at the
  screenshots after UI changes, in both themes.

## Commands

- `npm install`: first time
- `npm run tauri dev`: run the app with hot reload
- `npm run tauri build`: release build + installers (`src-tauri/target/release/bundle/`)
- `npm run build`: typecheck + build frontend only
